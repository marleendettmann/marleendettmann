# Marleen Dettmann

*Dr. rer. medic. · Demographer · Data Analyst · Scientific Software Development*

## About

My work focuses on statistical data analysis and modelling, including
population and household projections, epidemiological analyses, health
services research, and real-world data (RWD).

I develop reproducible analytical workflows, interactive visualizations, and
software tools for scientific and applied research.

## Software Projects

### [Kontextschleuse / Dokumentenschleuse](https://kontextschleuse.de/)

Kontextschleuse is the overarching project, and Dokumentenschleuse is its first
application: a functional offline prototype for preparing sensitive texts and
documents while preserving relevant context. It currently supports direct text
input, DOCX, and TXT files.

**Status:** Functional prototype in development, with initial external testing
underway.

### regionalepi — Regional Epidemiological Analysis

regionalepi is an R package and accompanying Shiny application for reproducible
analysis of regional infectious-disease surveillance data. It combines
demographic typologies, epidemiological indicators, and interactive
visualizations.

**Status:** In development.

## Selected Public Projects

### [DemographyDE](https://github.com/marleendettmann/DemographyDE)

Interactive R/Shiny application for exploring regional population projections
in Germany, including population trends, age structures, and geographic
patterns.

### [La Seyne Business Explorer](https://github.com/marleendettmann/LaSeyne_Entreprises)

Interactive R/Shiny dashboard for exploring business establishment data from
the French SIRENE register, including spatial distributions and economic sector
comparisons.

[Open the live application](https://marleen-dettmann.shinyapps.io/LaSeyne_Entreprises/)
